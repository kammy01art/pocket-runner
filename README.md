# Pocket Runner（試作）

自分の持っている GameMaker のゲームを、ブラウザの中で動かすための試作です。
ゲームを動かす部分には [Butterscotch](https://github.com/ButterscotchRunner/Butterscotch) の WebAssembly 版を使っています（`engine/` を参照）。

公開ページ: https://kammy01art.github.io/pocket-runner/

このアプリにゲームは入っていません。自分で購入したゲームのデータを使ってください。
ゲームのフォルダや ZIP を選ぶと、そのブラウザの保存領域（OPFS）にだけ取り込まれ、どこにも送信されません。

## PC で動かす

Python 3 が必要です。

```
python devserver.py --port 8765 --game-dir "C:\Program Files (x86)\Steam\steamapps\common\Undertale"
```

ブラウザ（Chrome 137 以降）で http://localhost:8765/ を開きます。

- 「ZIPを選ぶ」: ゲームフォルダを ZIP にまとめたものを取り込む（スマホはこちらだけ）
- 「フォルダを選ぶ」: Steam のゲームフォルダをそのまま取り込む（PC のみ）
- 「開発用：PC の〜から取り込む」: `--game-dir` で渡したフォルダを取り込む（localhost のときだけ表示）

## スマホに取り込む

1. PC で Steam のゲームフォルダを右クリック →「圧縮先」→「ZIP ファイル」
2. できた ZIP を iCloud Drive や Google ドライブなどに置く
3. スマホでこのアプリを開き、「ZIPを選ぶ」から ZIP を選ぶ

ZIP の中でフォルダに入っていても、`data.win` があるフォルダを見つけて取り込みます。

## 操作

### キーボード

アンダーテイルの場合: 矢印キーで移動、Z / Enter で決定、X / Shift でキャンセル、C / Ctrl でメニュー。

### タッチ

指で触れる端末では、画面にボタンが出ます。

PC では、上のバーで表示を選べます（最初は横持ち。選んだものは次回も使われます）。

- 横持ち / 縦持ち: iPhone 15 Pro の実寸（393×852）の枠で、スマホでの見え方を再現する。ウィンドウに収まるように全体を縮めるので、ボタンや文字の比率は実機と同じ。ボタンや十字キーはマウスでも押せて、キーボードで押したキーも画面に映る
- 画面だけ: ゲーム画面だけを大きく出す

PC でスマホと同じ全画面のタッチ表示にしたいときは、URL に `?touch` を付けます。

見た目は、本物のゲームボーイを操作しているような、暗めの焦げ茶の本体です（色は `style.css` の「本体の色」の変数で変えられます）。アンダーテイルの要素は、ゲーム機のコラボ本体のようにさりげなく入れています（電源ランプの赤いハートと「SOUL」、画面まわりの赤と金の線、「DOT MATRIX WITH DETERMINATION」、ロゴのハート、十字キーの真ん中のハートの刻印）。

- 横持ち: ゲームボーイアドバンスのように、ゲーム画面を真ん中に、移動を左、Z・X を右に分ける
- 縦持ち: 初代ゲームボーイと同じ並び
- 移動は十字キー。ゲーム中のメニューで、スティック（3DS のスライドパッドのようなもの）に切り替えられる。どちらも左側のどこに触れても、真ん中から指への向きで動く。上下左右の真上から ±30° は1方向、そのあいだは斜め
- Z（けってい）・X（もどる）は、ゲームボーイの A・B の位置。よく押す Z はひと回り大きい。Z は赤、X は金色で、文字はボタンの表面に薄く印字
- 「SYSTEM」でゲーム中のメニューを開き、「MENU」はゲームのメニュー（C キー）。メニューを開いているあいだもゲームは止まらない

### ゲーム中のメニュー（SYSTEM）

- がめんの むき（スマホだけ）: 「よこ」「よこ（ぎゃく）」「たて」から選ぶ。端末を傾けても勝手には切り替わらず、選んだ向きと端末の向きが違うときは本体ごと 90° 回して表示する（寝ころんで遊ぶときなど）
- いどうの そうさ: 「じゅうじキー」「スティック」を切り替える
- 右上の数字: 1秒あたりのコマ数（fps）。なめらかさの目安。アンダーテイルはもともと 30fps
- その下: 最後にセーブした時刻。アンダーテイルはセーブポイント（黄色い星）でしかセーブされない
- ゲームにもどる / しゅうりょうする

選んだ向きと操作は、次回も使われます。

文字は DotGothic16（SIL Open Font License）を Google Fonts から読み込んでいます。

## ホーム画面に追加して使う

- iPhone の Safari で開き、共有ボタン →「ホーム画面に追加」。焦げ茶のゲームボーイと赤いハートのアイコンになる
- ホーム画面から開いたときと Safari で開いたときとで、保存領域は別々。ゲームは、ふだん使う方で取り込む
- アイコンを新しくするには、ホーム画面のアイコンを消して追加し直す（消すと取り込んだゲームとセーブも消えるので注意）
- ピンチやダブルタップでは拡大しない。もし拡大されても、自動で元の倍率に戻す
- Android の Chrome では、トップの「ホーム画面に追加する」ボタン（出ているとき）か、Chrome のメニューの「ホーム画面に追加」「アプリをインストール」から追加できる

## Android

Android の Chrome で動きます。iPhone と同じ機能に加えて、次のことをしています。

- 遊んでいるあいだは全画面にし、メニューで選んだ向き（よこ・よこ（ぎゃく）・たて）に画面を固定する。固定できないときは、iPhone と同じく本体ごと回して合わせる
- 「戻る」ボタンや戻るジェスチャーでアプリが閉じないよう、代わりにゲーム中のメニューを開け閉めする
- ボタンを押すと軽く振動する

遊んでいるあいだは画面が暗くならないようにしています（iPhone も同じ）。

## 動作環境とエンジン

| | 標準のエンジン（JSPI） | 互換エンジン（Asyncify） |
| --- | --- | --- |
| 使われるブラウザ | Chrome 137 以降、Safari 27 以降（iOS 27 以降）、Firefox 153 以降 | それより古い Chrome 109 以降、Safari 26（iOS 26）、Samsung Internet など |
| 速さ | 速い。コマの間隔を画面の書き換えにそろえる | 少しゆっくり（エンジンが約1.5倍の大きさ） |

どちらを使うかは自動で決まり、トップの「動作環境」に出ます。保存領域（OPFS）への書き込み（Chrome 109 以降、Safari 26 以降）と WebGL 2 はどちらでも必要です。

## オフライン

一度開くと、アプリのファイル（エンジンを含む）が端末に保存され、通信がなくても起動できます（`sw.js`）。ゲームのデータとセーブは、もともと端末の保存領域にあります。

アプリを更新したときは、保存済みのファイルで起動しながら裏で新しいものを受け取り、次に開いたときから新しくなります。開発用サーバー（localhost）では、紛らわしいので URL に `?sw` を付けたときだけ有効です。

## なめらかさ

エンジンは次のコマまでタイマーで待つため、そのままだと画面の書き換え（60Hz / 120Hz）とずれて、コマの間隔がまばらになります。`app.js` でエンジンの「待つ」処理（`emscripten_sleep`）を差し替え、画面の書き換えの合図（`requestAnimationFrame`）にそろえています。画面が隠れていて合図が来ないときは、タイマーだけで進めます。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` / `style.css` | 画面 |
| `app.js` | 取り込み、エンジンの選択と起動、キー入力、タッチ操作、画面の向き、拡大の防止、Android 向けの全画面と「戻る」 |
| `zip.js` | ZIP の中身を読む（ブラウザ標準の機能だけで展開） |
| `sw.js` | オフラインでも開けるように、アプリのファイルを端末に保存する |
| `manifest.webmanifest` / `icons/` | ホーム画面に追加したときの名前とアイコン（元の絵は `icons/icon.svg`） |
| `engine/` | Butterscotch のビルド（AGPL-3.0）。`engine/compat/` は互換エンジン |
| `engine-build/` | 互換エンジンを組み立てるスクリプト |
| `devserver.py` | 開発用のローカルサーバー（127.0.0.1 のみ） |

## 既知の問題

- エンジンの 2026-10-18 の更新で、WebGL のシェーダーが組み立てられず画面が真っ黒になる不具合が入っている。`app.js` で応急処置済み（`uFogColor` を検索）。
- iPhone（Safari）でセーブが残らなかった。保存領域への書き込み方を `engine/butterscotch.mjs` で変えて対応（`engine/README.md` を参照）。
- 保存領域を使うため、localhost 以外では HTTPS が必要。
- Android は PC の Chrome でスマホの大きさにして確かめただけで、実機ではまだ確かめていない。
- エンジンは端末の言語をいつも「英語」と答える。アンダーテイルは、日本語の端末なら初めて遊ぶときに言語設定（`config.ini`）を日本語にしておくことで対応している。
